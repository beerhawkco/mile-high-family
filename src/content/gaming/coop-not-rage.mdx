Versus modes turn a living room into a small civil war. Co-op keeps the evening in the same country. Pick games where you share a goal: build, rescue, explore. Skip ranked anything.

## House rules

- Same couch if you can
- One “I’m stuck” pause per person
- No chat with strangers on a weeknight
- 40 minutes, then stretch, then maybe one more world

## After the session

Ask “what should we try next time?” not “who won?” If someone is hot, the console is off. The game will still be there. The controller should also still be there.
